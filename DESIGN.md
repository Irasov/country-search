# DESIGN

## 1. Как устроена отмена устаревших запросов

**Механизм.** На каждый запрос создаётся свой `AbortController`
(`src/searchController.ts`, функция `run`). В контроллере хранится один
«активный» запрос. На каждый вызов `input()`, а также на `retry()` вызывается
`cancelActive()`, то есть `abort()` предыдущего запроса. Это происходит сразу,
не дожидаясь `debounce`.

`searchCountries` (`src/searchCountries.ts`) объединяет сигнал вызывающего и
таймаут: `AbortSignal.any([signal, AbortSignal.timeout(ms)])`. Один объединённый
сигнал передаётся в `fetch` и покрывает и ожидание ответа, и чтение тела.

В `catch` ошибка проходит через `classifyError` (`src/classifyError.ts`):

| Причина                              | `name`         | Что видит пользователь                           |
| ------------------------------------ | -------------- | ------------------------------------------------ |
| Свой `abort()` (новый ввод, очистка) | `AbortError`   | ничего, молча игнорируется                       |
| Нет ответа за `timeoutMs`            | `TimeoutError` | «Сервер слишком долго не отвечает» + «Повторить» |
| Статус не 2xx и не 404               | `HttpError`    | «Сервер вернул ошибку N» + «Повторить»           |
| Обрыв сети                           | `TypeError`    | «Нет соединения» + «Повторить»                   |

404 не исключение: `searchCountries` возвращает `[]`, UI показывает «ничего не найдено».

**Почему не флаг «актуальный ли это ответ».**

- Флаг скрывает симптом, а запрос продолжает жить: занимает соединение,
  трафик, серверное время и квоту API (у API есть статус 429). Реальная отмена
  освобождает всё это.
- Между вводом нового символа и срабатыванием `debounce` проходит время.
  Устаревший ответ успевает прийти и отрисоваться под уже новым текстом.
  Поэтому отмена привязана к каждому вводу, а не к моменту запуска нового запроса.
- Отмена различима по причине (`AbortError` против `TimeoutError`). С флагом
  пришлось бы вручную отличать «отменили мы» от «запрос упал».
- Корректность не зависит от порядка прихода ответов, и каждое место чтения
  результата не нужно сверять с актуальностью.

**Проверка.** `tests/searchRace.test.ts` использует настоящие `searchCountries` и
контроллер. Мок `fetch` реагирует на `signal` и отклоняет промис причиной
отмены, как настоящий. Порядок ответов инвертирован: поздний запрос отвечает
первым. Если убрать `cancelActive()`, тест падает.

**Ограничение.** Контроллер полагается на то, что функция `search` реагирует на
переданный `signal`. `fetch` и `searchCountries` реагируют. Своя реализация
`search`, игнорирующая сигнал, получила бы устаревший результат.

## 2. Задержка debounce: 300 мс

Значение лежит в константе `DEFAULT_DEBOUNCE_MS` (`src/searchController.ts`).

**Без debounce (0 мс).** Каждое нажатие клавиши запускает запрос и отменяет
предыдущий. Набор `spain` даёт пять запросов, из которых четыре отменяются.
Это нагрузка на сеть и на API (есть 429) и мигающий индикатор загрузки
на каждый символ. Промежуточные результаты (`s`, `sp`) пользователю не нужны.

**Слишком большая (например, 1000 мс).** Интерфейс кажется «мёртвым»: человек
закончил печатать и секунду ждёт, не зная, сработал ли ввод. Именно поэтому
`loading` показывается сразу в `input()`, до запуска запроса.

**Почему 300.** Это эвристика, а не измерение. Паузы между нажатиями при
обычной печати измеряются десятками-сотнями миллисекунд, и 300 мс обычно
пересекает «паузу между словами», но не ощущается как задержка. Значение
передаётся параметром `debounceMs`, поэтому его легко поменять или протестировать.

**Что debounce не делает.** От устаревших ответов защищает только отмена
(раздел 1). Debounce уменьшает количество запросов, но не гарантирует порядок.

## 3. Сложность (Big O)

`mapCountryResponse(raw)` в `src/mapCountryResponse.ts`. Пусть n это число стран,
а l, c, b числа языков, валют и границ одной страны.

- **Время: O(n·(l + c + b)).** Один проход `map` по странам, внутри `map` по
  языкам и валютам и копирование границ. На практике l, c, b ограничены
  единицами-десятками, поэтому по сути O(n). `pickFlagUrl` перебирает три
  кандидата, то есть O(1).
- **Память: O(n·(l + c + b)).** Строятся новые объекты и копии массивов,
  входные данные не мутируются (есть тест).
- Эндпоинт `/name/{query}` возвращает страны, чьё имя содержит запрос, то есть
  десятки записей. Основная стоимость ответа приходится на `JSON.parse` и сеть,
  а не на маппинг.

## 4. Принципы чистого кода и где они применены

| Принцип                               | Где                                                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Чистые функции, без побочных эффектов | `mapCountryResponse`, `classifyError`, `src/format.ts`. Вход не мутируется                                                           |
| Единственная ответственность          | `debounce` только задержка, `classifyError` только классификация, `searchCountries` только запрос, `render.ts` только отрисовка      |
| Логика отделена от DOM                | `searchController.ts` и всё остальное в `src/` кроме `dom.ts`, `render.ts`, `main.ts` не трогают DOM и тестируются в Node            |
| Внедрение зависимостей                | `createSearchController({ search })`: в тестах подставляется управляемый поиск, в приложении `searchCountries`                       |
| Нет «магических чисел»                | `DEFAULT_TIMEOUT_MS`, `DEFAULT_DEBOUNCE_MS`, `EMPTY`                                                                                 |
| Выражение состояний типами            | `SearchState` и `Failure` это размеченные объединения. `switch` в `render.ts` и `failureMessage` проверяется компилятором на полноту |
| Ранние возвраты                       | `searchCountries` (404, затем `!ok`), `input()` (пустая строка)                                                                      |
| Безопасность по умолчанию             | Динамический текст только через `createElement` и `append(string)` (`src/dom.ts`), без `innerHTML`                                   |
| Неизменяемость данных на границах     | `borders: [...]` в `mapCountry`, тест на отсутствие общих ссылок                                                                     |
